# 🚀 Jenkins Plugin Installation

## 🎯 Objective

Install a plugin in Jenkins using the Plugin Manager.

---

## 📋 Prerequisites

- Jenkins Installed
- Jenkins Running
- Admin Access to Jenkins
- Internet Connectivity

---

## 🛠️ Installation Steps

### Step 1: Open Plugin Manager

Navigate to:

```text
Manage Jenkins → Plugins
```

### Step 2: Open Available Plugins

Click the **Available Plugins** tab.

### Step 3: Search Plugin

Enter the plugin name in the search box.

### Step 4: Select Plugin

Check the checkbox next to the required plugin.

### Step 5: Install Plugin

Click:

```text
Install
```

### Step 6: Wait for Installation

Allow Jenkins to download and install the plugin.

### Step 7: Restart Jenkins (If Required)

Restart Jenkins if prompted after installation.

### Step 8: Verify Installation

Navigate to:

```text
Manage Jenkins → Plugins → Installed Plugins
```

Search for the plugin name to confirm successful installation.

---

## ✅ Verification

- Open **Manage Jenkins → Plugins**
- Go to **Installed Plugins**
- Search for the installed plugin
- Plugin should appear in the list

---

## 🎉 Conclusion

The Jenkins plugin has been successfully installed and verified.
